# DataFlow

Um projeto prático de estudo em análise e engenharia de dados, desenvolvido para explorar — passo a passo — como transformar dados públicos em informações úteis.

## Objetivo

Construir um fluxo de dados simples, entendendo cada etapa do processo: da coleta até a análise e apresentação dos resultados.

## Etapas do projeto

- [ ] **Coleta:** obter dados de uma fonte pública, como uma API.
- [ ] **Processamento:** explorar, limpar e transformar os dados com Python.
- [ ] **Armazenamento:** organizar os dados e praticar consultas com SQL.
- [ ] **Análise:** investigar os dados e produzir indicadores e visualizações.
- [ ] **Automação:** organizar a execução do fluxo para que ele possa ser reproduzido.

As etapas serão implementadas gradualmente. A ideia é priorizar fundamentos, documentação e evolução contínua, sem adicionar ferramentas antes de entender sua necessidade.

## Tecnologias

- Python
- Pandas
- SQL (em etapa futura)
- Git e GitHub

## Estrutura inicial

```
dataflow/
├── data/
│   ├── raw/          # Dados originais
│   └── processed/    # Dados após tratamento
├── notebooks/        # Exploração e análises
├── src/              # Código-fonte do projeto
├── tests/            # Testes

```
